# Ocean Health Index Analysis

This repository contains the code, data, and final report for my project analyzing the Ocean Health Index (OHI) from 2012 to 2024.

## Project Structure

- `data/`: Contains the raw data file `ocean_health_index.csv`.
- `code/`: Contains the R Markdown script `OHI Analysis.Rmd` used for all data processing and analysis.
- `output/`: Contains the final report `Ocean-Health-Index.html`, which is generated by running the `Makefile`.
-`Makefile`: The main file for generating the final report.

## How to Generate the Final Report

1. **Prerequisities:** Make sure you have R, RStudio, and the necessary R packages installed. The required packages (`tidyverse`, `knitr`, `ggplot2`, `kableExtra`) are loaded at the beginning of the `OHI Analysis.Rmd` script.

2. **Run the Makefile:** Open a terminal (or command prompt) in the root directory of this project (`final-project-ocean-health/`) and run the command:
    ```bash
    make
    ```
    This will execute the OHI Analysis.Rmd, creating the HTML report (Ocean-Health-Index.html) in the output/ folder.

### Create the `Makefile`

The `Makefile` is a simple text file that tells the computer how to build your final output. It's the core of reproducibility. Create a file named `Makefile` (no extension) in the root of your project folder (`final-project-ocean-health/`).

Paste the following into it:

```makefile
# Define the target (the final report) and its dependency (the Rmd script)
output/Ocean-Health-Index.html: code/analysis.Rmd data/ocean_health_index.csv
    # Create the output directory if it doesn't exist
    mkdir -p output
    # Run the R script to knit the Rmd into an HTML file, placing it in the output folder
    Rscript -e "rmarkdown::render('code/analysis.Rmd', output_file = '../output/Ocean-Health-Index.html')"
